# Klipper Configuration

This directory is reserved for tested Klipper configuration files.

Do not publish an unverified `printer.cfg` as final. Add configuration here after confirming:

- SKR Mini E3 V3.0 pin mapping,
- motor direction and rotation distance,
- endstop / DIAG jumper configuration,
- SuperPINDA probe pin and offset,
- heater and thermistor configuration,
- fan mapping,
- safe homing and bed mesh settings.
